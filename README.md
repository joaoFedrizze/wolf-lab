# Projeto de Estudo --- Arquitetura Full Stack (Fictício)

Este repositório apresenta um **projeto totalmente fictício**,
desenvolvido apenas para fins de estudo e demonstração de arquitetura
full stack moderna.\
O objetivo é explorar diferentes frameworks, boas práticas e a
integração entre front-end, back-end e banco de dados.

------------------------------------------------------------------------

## 🧩 Tecnologias Utilizadas

### **React --- Front-end do Cliente Final**

-   Interface destinada ao usuário final.
-   Focada em experiência, fluidez e responsividade.
-   Componentização e organização baseadas em boas práticas modernas.

------------------------------------------------------------------------

### **Angular --- Dashboard Administrativa**

-   Painel para gerenciar conteúdos e dados da aplicação.
-   Utiliza sinais (signals), serviços, modularização e patterns atuais.
-   Voltado para controle interno e edição das informações.

------------------------------------------------------------------------

### **NestJS --- Back-end**

-   API desenvolvida com arquitetura modular.
-   Organização clara entre controllers, services e DTOs.
-   Responsável por conectar o front-end ao banco de dados.

------------------------------------------------------------------------

### **MongoDB --- Banco de Dados**

-   Utilizado em formato JSON para simular documentos.
-   Ideal para estudos de CRUD, queries e modelagem não relacional.

------------------------------------------------------------------------

## 📝 Objetivo do Projeto

Este projeto foi criado **somente para estudo**.\
Aqui são explorados conceitos como: - Comunicação entre sistemas; - Boas
práticas de organização de código; - Testes de arquitecturas
diferentes; - Integração entre front-end e back-end; - Estruturação de
APIs e manipulção de dados.

------------------------------------------------------------------------

## 📌 Observação

Este projeto **não representa um produto real**, nem dados reais.\
Serve apenas como base para aprendizado, testes e demonstrações.

------------------------------------------------------------------------

## 🚀 Como rodar o projeto

Cada parte deste repositório possui seu próprio README explicando
instalação e execução.\
Basta acessar a pasta correspondente:

    /client-react       -> front-end final em React  
    /dashboard-angular  -> painel administrativo em Angular  
    /server-nest        -> back-end em NestJS  
    /database           -> JSONs simulando documentos do MongoDB
